# VOKA YouTube Probe（维护者手动测量）

此扩展只在维护者手动打开的视频页面运行。它把视频编号为 `video #1`、`video #2` 等，只在 `chrome.storage.local` 保存字幕类型、数字、布尔值、HTTP 状态和固定错误名；不会保存视频 ID、标题、URL、频道名或字幕文本。方法 B 需要手动开启播放器字幕，扩展不会替维护者按键。

## 操作步骤

1. 在仓库根目录构建扩展：

   ```sh
   npm run probe:youtube
   ```

2. 在 Chrome 地址栏打开 `chrome://extensions`，开启**开发者模式**，点击**加载已解压的扩展程序**，选择仓库中的 `prototypes/youtube-probe/dist`。

3. 在 YouTube 搜索结果里挑选不同类型的视频：

   - **人工英文字幕**：结果卡片有 CC 标记；播放器字幕菜单里有 English，且没有“自动生成”字样。
   - **仅自动英文字幕**：字幕菜单里的 English 标为“自动生成”，没有人工 English 轨道。
   - **仅其他语言字幕**：字幕菜单只列出非英文轨道。
   - **无字幕**：结果卡片没有 CC 标记，播放器菜单也没有字幕轨道。
   - **Shorts**：至少打开一个 `/shorts/` 视频；扩展会自动标记 Shorts 类型。

4. 每个视频打开后，等右上角面板完成自动记录；然后在播放器上按一次 **C** 开启字幕，以测试方法 B。不要通过扩展面板按键。

5. 在至少一个有字幕的视频上把鼠标移到扩展显示的字幕框，再移开一次；在同一视频上按 **T** 切换影院模式、按 **F** 切换全屏，确认框的位置并保持播放状态。播放器暂停/播放自测会在视频正在播放时自动执行一次，暂停约 1 秒后尝试恢复；如果你在这期间操作播放器，自测会让位给你的操作。

6. 点击工具栏上的 VOKA YouTube Probe 图标打开汇总页，检查样本清单与结果表，点击**复制汇总 JSON**，再把 JSON 粘贴回协调者。复制内容只有聚合计数、状态、错误名和显示尺寸，不含单条视频记录或页面内容。

7. 完成后回到 `chrome://extensions`，找到 VOKA YouTube Probe，点击**移除**。

## 构建说明

`npm run probe:youtube` 使用本目录的 Vite 配置生成 `dist/`。该目录是构建产物，不提交到 Git。扩展只声明 `storage` 权限和 `*://www.youtube.com/*` 主机权限；字幕轨道请求只使用播放器数据提供的同源 timed-text URL，方法 B 仅观察播放器自己的请求。
