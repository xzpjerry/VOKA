# English data build

`npm run data:build` runs `python3 tools/data/build.py` (Python 3.10+, standard library only). Network is needed on the first run; subsequent runs verify and reuse `.cache/data/`. Delete that cache to test fresh downloads. Every URL and SHA-256 digest is pinned in `sources.json`, including notices. A changed upstream archive fails closed; inspect an upstream change and deliberately update pins before rebuilding. Build output uses sorted JSON keys and a fixed generation date for this data release; identical upstream bytes yield identical packs. A new data release must update `VERSION`, `DATE`, source pins, tests and acceptance evidence together.

Generated JSON packs are committed under `public/data/`. This keeps normal clean-checkout extension builds offline and reproducible without Python or upstream availability. Raw data is approximately 11.8 MB and gzip approximately 3.34 MB, below the spec's 5 MB compressed estimate. Vite copies the files without bundling them into JavaScript. They load once on demand in the background; content scripts need not carry dictionaries. Do not combine the independently licensed level files or relabel any data as MPL.

* `cefrj.json`: official CEFR-J Wordlist 1.6 ZIP, XLSX `ALL` sheet (not `ALL_sep`, which loses first spelling order). Copyright Tono Laboratory, Tokyo University of Foreign Studies; attribution terms and exact citation in metadata.
* `octanove.json`: Octanove C1/C2 1.0, pinned openlanguageprofiles Git commit. CC BY-SA 4.0; modifications recorded in metadata, adapted pack stays CC BY-SA 4.0.
* `oewn.json`: latest published release at implementation time, OEWN 2025. All single-word lemmas, including names, hyphens and apostrophes; whitespace and underscore headwords removed. Case/NFC/apostrophes normalized. Homographs and POS merged; first two distinct upstream definitions per POS in stable source-file/sense order. Adjective satellites group with adjectives. CC BY 4.0 plus Princeton notice.
* `readings.json`: pinned CMUdict commit, ARPAbet mapped to broad US IPA (including stress, reduced AH0/ER0). First pronunciation retained. Numbered alternates are not POS labels; CMUdict has no POS annotation, so those readings are unlabelled. This is a deterministic phoneme transliteration, not syllabification or a context-aware heteronym predictor.
* `oewn-readings.json`: US-labelled OEWN pronunciations grouped by POS, used only if CMUdict is missing. Unmarked/GB-only readings are omitted rather than labelled US.
* `morphology.json`: OEWN WNDB `*.exc` irregular lists grouped by POS, plus WordNet Morphy suffix replacements. Every candidate is checked against the lexicon. Irregular exceptions take priority over suffix stripping for that POS. These are original rule implementations, with Princeton notices retained; no wink code is copied.
* `gloss-zh.json`: separately generated Simplified Chinese native glosses for single-word OEWN lemmas, produced by `tools/gloss/generate.py` from the committed `oewn.json` senses. `{lemma: {pos: [senses]}}`; at most three senses per POS and ten Han characters per sense. CC BY 4.0 with the OEWN attribution; the pack records every model used, the prompt SHA-256, generated date, its own data version, `complete`, entry count and an exact `missingLemmas` list. The current committed pack is **partial** and must not be described as complete; `docs/research/gloss-full/progress.json` records exact batch/lemma progress and the resume command. It is not part of `data:build` and does not modify `oewn.json`; `data:build` reuses its metadata in `attributions.json` and `sizes.json`.
* `attributions.json`: all pack metadata and complete upstream CMU, OEWN and Princeton notices, rendered in Options. It includes the native-gloss pack and its model/prompt provenance. `sizes.json`: raw and deterministic gzip measurements.

Level tuples are `[level, variants[]]`; source files normalize within their own dataset only. At load time lowest levels are selected across both files, and standalone spelling variants are folded into the first spelling's Key (`am` → `a.m.`, `sulphur` → `sulfur`). This gives A1 1050 / A2 1200 / B1 2085 / B2 2383 / C1 909 / C2 868, 8495 unique Keys. CEFR-J 1.6 differs from the spec's 1.5 baseline; alias folding also removes two duplicate Keys. `saw` and `see` are both A1 in the official file, so ADR-0001's tie rule prefers `saw` for the surface form `saw`.

`src/data/index.ts` exports `loadData()` for a cached async load, then synchronous `data.lookupEntry(key)` and `data.lemmaCandidates(form)`. Async convenience exports have the same names. Entries contain `lemma`, `level` (empty when ungraded), `Variants`, `Reading`, `GlossTarget`, `GlossNative`, `dictionaryStatus` and `message` (`词典没有` when OEWN is missing). Native glosses are merged across spelling variants and capped at three senses per POS; entries absent from the partial pack (and missing OEWN words) stay empty rather than inventing a gloss, and the UI falls back to `GlossTarget`. Import iterates `data.pack.entries` (levels only); dictionary lookup covers the whole OEWN single-word lexicon. No ECDICT, Wiktionary or Kaikki data is downloaded or distributed.

Section 7.3 publication gates remain: confirm CEFR-J embedded-product terms and Octanove construction provenance with the rights holders before public-store publication. This pipeline does not claim those confirmations occurred.
