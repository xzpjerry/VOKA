# Native gloss pilot

See [pilot method, exact commands, outputs and limitations](../../docs/research/gloss-pilot/README.md). This standard-library Python tool uses authenticated non-interactive Codex CLI for `gpt-6-luna`/`gpt-6.1-sol` and OpenCode CLI for `opencode/deepseek-v4.1-flash-free`; it does not use an API key or generate the full dictionary. `prompt.txt` is the shared versioned prompt. Keep the three model directories with their sample as one research snapshot.
