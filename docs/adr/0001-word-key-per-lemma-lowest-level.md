# 词条 Key 按 lemma 定义、永不改变，等级取各词性最低

词条 Key 是 VOKA 笔记的第一个字段，也是 Anki 判重的依据；一旦写进用户的 Anki 收藏就无法安全地改，所以它的规则必须在公开发布前定死。我们决定：一个 lemma 只对应一条笔记，Key 是 `语言:规范化 lemma`，例如 `en:lead`。规范化指转成小写、统一成 Unicode NFC、弯撇号转成直撇号，保留连字符和变音符号。不同词性、同形异义词（lead 铅 / 引导）、只靠大小写区分的词（may / May）、拼写变体（color / colour，Key 取词表里的第一个拼写）都合并在这一条笔记里。Key 永不修改，以后也不在原有笔记上拆分义项。每个词条只有一个**词条等级**，取它在等级词表中各词性等级的最低值。比如 book 名词 A1、动词 B1，词条等级就是 A1。

## Considered Options

- **按 lemma + 词性分笔记**：词表的原始粒度就是这样，但阅读时无法按上下文判断词性，同一个词形会对应多张卡；而且同一个词的不同词性在 Anki 里分开排程，不符合「一个词一张词卡」。
- **一个词可同时属于多个等级**（PRD 原方案的等级成员标签）：目标等级只要在其中就高亮。CEFR-J 加 Octanove 里约 9%（758 个）的词跨等级，这样做会让 B1 学习者读到 "a book" 也被高亮，噪音大。取最低等级的代价是：较高等级的词性用法（如 book 的动词用法 B1）不会成为目标；词卡背面仍会列出全部词性的释义。
- **Key 保留大小写**：Anki 判重区分大小写（实测），保留大小写会让 `en:May` 和 `en:may` 成为两条笔记，而在本词表中只靠大小写区分的只有 4 组词，不值得为此增加复杂度。

## Consequences

- 在当前数据下每个词只属于一个等级牌组，PRD 的「跨等级复用」只留给以后词表版本更新的情况。
- 读到的词形若能还原成多个 lemma（saw → saw / see），默认匹配到词条等级最低的候选；等级相同时优先词形本身就是 lemma 的那个。用户可以在弹窗里改选，之后保存例句、加入 Anki、上下文复习都按用户选的那个 Key。
- 词表中的多词短语（154 条）在 P0 不导入。
