# YouTube 字幕获取与播放器控制调研

日期：2026-11-01。探测使用 Puppeteer 启动的全新 Chrome for Testing 配置，没有登录账号。

## 1. 取字幕的方式

本轮没有拿到可播放的视频页，因此无法给三种方法作成功率或稳定性排名。YouTube 搜索返回的 37 个候选页，其 `playabilityStatus.status` 全部为 `LOGIN_REQUIRED`，每页的 `captionTracks` 数量都是 0；随后另一个全新配置的页面加载返回 HTTP `429`，播放器和视频元素均未出现。页面响应中的 `videoDetails.videoId` 为空，覆盖搜索候选 ID 时发生了保存错误，因此当前缓存只有 37 条匿名观测，未保留可重跑的 ID 清单。

| 方法 | 本轮观测 | 令牌、状态码与完整度 |
|---|---|---|
| A. 读取播放器数据并请求轨道 URL | `0/37` 找到字幕轨道；不能从空轨道列表发起字幕请求 | 字幕 URL 不存在，字幕请求状态码、是否需要签名参数、cue 数与完整度均未测到 |
| B. 通过播放器开启字幕并捕获 timed-text 响应 | 未执行：播放器被 `LOGIN_REQUIRED` 阻止 | 没有可供统计的 timed-text 请求或 HTTP 状态 |
| C. 读取播放器当前字幕 DOM | 未执行：没有播放器 DOM | 当前行、cue 数与首 cue 时间均未测到 |

**候选实现顺序（尚未由本轮实测验证）**：优先读取页面播放器数据中的轨道，再在页面上下文尝试 JSON3、VTT 字幕 URL；直接轨道不可用时，尝试开启播放器字幕并复用其 timed-text 响应；DOM 只适合作为当前行显示的最后回退，不能替代整片 cue 列表。不要在本轮结果之外宣称这些方法已验证。

## 3. 播放器控制

**未回答。** 被限制的页面没有 `<video>` 元素或 `#movie_player` API，所以本轮无法实测当前时间、暂停/播放、seek 或用户输入事件。

重跑探针时会分别读取 `video.currentTime` 和播放器 `getCurrentTime()` / `getPlayerState()`，由脚本暂停再播放，再用 Puppeteer 点击播放器播放按钮和进度条，观察媒体元素的 `play`、`pause`、`seeking`、`seeked` 事件。媒体事件本身不携带“由用户还是 VOKA 发起”的来源字段；实现时应在 VOKA 自己调用暂停/播放期间设置短暂的内部标记，再把标记之外、紧随播放器用户输入的事件视为外部状态变化。这个区分策略尚未在 YouTube 页面验证。

## 4. 页面切换、显示模式与悬停原型

**未回答，未完成在线验收。** 页面门槛阻止了 SPA 切换、全屏、影院模式和 overlay 测试；因此本轮没有验证 `yt-navigate-finish`、播放器尺寸变化或悬停暂停/恢复。

候选实现是在导航开始时清理旧视频的监听器和 overlay，在 `yt-navigate-finish` 后重新查找播放器与视频，并以 URL/`popstate` 变化作为补充信号。Overlay 应挂在播放器内部并按 `video.currentTime` 查 cue；悬停时只在视频原本正在播放的情况下暂停，离开时只恢复由该 overlay 暂停的视频。探针包含这些自动检查，但本轮没有可用 cue 来运行它们。影院模式、全屏和 SPA 生命周期仍须在真实视频上验证。

## 5. 权限、用户提示与风险

当前扩展的 `optional_host_permissions` 已允许按站点申请权限；`rememberSite()` 使用 `sitePattern(host)` 请求单个主机授权，站点模式会注册相应的内容脚本。YouTube Watch 与 Shorts 都在 `www.youtube.com` 时，运行时最小权限为 `*://www.youtube.com/*`；继续使用现有按站点授权流程即可，不需要为该功能新增必需的全站权限。该结论依据仓库中的 manifest 和站点授权代码；字幕轨道 URL 的最终主机本轮未能读取。

字幕不可用时建议区分“没有轨道”和“暂时无法读取”：

- 没有可用轨道：**“此视频没有可读取的字幕。请在 YouTube 中开启字幕，或换一段视频。”**
- 页面或轨道请求暂时不可访问：**“暂时无法读取此视频字幕。请在 YouTube 页面重试，或使用播放器原生字幕。”**

主要风险是 YouTube 内部播放器数据、轨道 URL、播放器方法和字幕 DOM 类名并非稳定的扩展接口；站点更新、签名参数变化、访问频率限制、区域/视频限制或字幕关闭都可能改变结果。字幕 URL 是否需要短期签名、额外 token 或其他参数，本轮没有测到，不能据此作产品承诺。

### 重跑命令

在仓库根目录执行。脚本要求 `.cache/youtube/videos.json` 有至少 15 个有效视频 ID；当前缓存不满足此条件，命令会写出 `CANDIDATE_IDS_UNAVAILABLE` 并停止，不发起新请求。补全仅存于该忽略文件的候选 ID 后，脚本每次会创建并删除新的临时 Chrome profile，并把汇总与匿名序号结果写到 `.cache/youtube/results.json`；不保存字幕文本、标题、页面 DOM 或请求 URL。

```sh
npx puppeteer browsers install chrome
npx tsx scripts/research-youtube-subtitles.ts
```
